The project repo for PharmaLedger under SIH26...

REST APIs and async image /ocr jobs - fast api in python

computer vision - open cv

rule engine: custom python - JSON/DB version ruled mapped to legal metrology clauses

Auth and security - JWT + RBAC - officer superviser 

Reports- report lab, weasy printd for evidence - embedded pdfs

deployment- docker compose- cloud VM/VPS
